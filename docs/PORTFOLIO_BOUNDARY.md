# Portfolio and privacy boundary

This repository is a front-end portfolio prototype, not a live commerce system.

- The catalogue, product imagery, prices, delivery flow, promotion, profile, orders and policies are demo content.
- No payment fields are collected. A production checkout must hand payment collection to a PCI-compliant provider.
- Delivery details are used only to demonstrate the confirmation screen and are not retained in demo order history.
- Optional profile data, saved addresses, the bag, wishlist and demo orders remain in the visitor's own browser storage. The interface includes a control to remove them.
- The project contains no customer records, production inventory, fulfillment information, credentials, analytics identifiers or payment keys.

Before turning this into a production shop, replace every demo detail, obtain approval for the brand and artwork, connect a secure backend, and publish final legal, tax, returns and privacy materials.
